# BAIZONA — QUIET POWER
## Design Constitution v1.0

> **Looks simple. Feels premium. Works fast.**

---

## Kanuni Kuu 13

### 1. SPACE ni Kitu cha Kwanza
Tusijaze kila sehemu. **Empty space** inafanya ionekane expensive.

### 2. Hierarchy, Sio Cards Nyingi
- LEVEL 1: Mauzo ya leo (display)
- LEVEL 2: Stock inayohitaji attention
- LEVEL 3: Recent activity
- LEVEL 4: Deep analytics

### 3. HERO kwa Business, Sio Picha
Hero ni **namba** — sio picha. Background subtle.

### 4. Typography ndiyo Weapon
overline (tiny, uppercase) → DISPLAY (huge, bold) → description (quiet) → CTA (small, strong)

### 5. Navigation Inatoweka
Active page: mstari mdogo chini. Sio button kubwa.

### 6. Buttons: Chache na Strong
Primary: + UZA (orange). Secondary: outline. Tertiary: text pekee.

### 7. Motion ni Micro
0.2s cubic-bezier(0.4, 0, 0.2, 1). Sio fireworks.

### 8. Cards: Less Box, More Layout
Sio [card] nyingi. Ni layout nzuri.

### 9. Colors: Neutral + Accent Moja
Background: #F7F7F5. Text: #111111. Accent: #F97316 (orange).

### 10. Dark Mode Baadaye
Kwanza light iwe perfect.

### 11. Home ≠ Uza
Home: Calm, spacious. Uza: Dense, fast.

### 12. Tables/Lists: Clean
Sio grid za cards nyingi.

### 13. Icons: Consistent Line Icons
16px / 20px / 24px. Emoji: almost none.
