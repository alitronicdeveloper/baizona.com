# Baizona - Hardware Business Management System

Mfumo wa usimamizi wa maduka ya vifaa vya ujenzi (hardware) Tanzania.

## Constitution Yetu

> **Don't simplify the business. Simplify the interaction.**

## Tech Stack

- **Frontend**: React + TypeScript
- **Backend**: Go (Golang)
- **Database**: PostgreSQL
- **Local DB**: IndexedDB (Dexie.js)

## Muundo wa Project

- `docs/` - Documentation na Constitution
- `database/` - Database schema
- `backend/` - Go backend
- `frontend/` - React frontend

## Phase 1 - Core Features

1. UZA (Sales)
2. BIDHAA (Products)
3. STOCK (Inventory)
4. MAUZO (Sales History)
5. HOME (Dashboard)
6. WATEJA (Customers)
7. MADENI (Debts)

## Kanuni Kuu

1. Simple surface, powerful engine
2. Value before configuration
3. Never guess money
4. Progressive disclosure
5. Offline-ready architecture
